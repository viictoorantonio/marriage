# Casamento Leticia & Victor

Site de casamento com contagem regressiva, formulário de confirmação de presença integrado ao Google Sheets e informações do evento.

## Deploy

O site é automaticamente deployado no GitHub Pages a cada push na branch `main`.

## Como configurar

1. Faça push deste repositório para o GitHub
2. Vá em **Settings** > **Pages**
3. Em **Source**, selecione **GitHub Actions**
4. O deploy será feito automaticamente

## URL do site

Após o deploy, o site estará disponível em:
`https://seu-usuario.github.io/nome-do-repositorio/`

## Tecnologias

- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)
- Google Apps Script (para formulário)
- GitHub Pages (hosting)
- GitHub Actions (CI/CD)
